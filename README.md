# Playlist Bladwijzer

Een kleine web-app die per Spotify-playlist onthoudt bij welk nummer je gebleven was, en van daar kan hervatten.

- Werkt in Safari op Mac en iPhone (zet ze op je beginscherm via *Deel → Zet op beginscherm*).
- Inloggen via Spotify (PKCE, geen geheim nodig).
- Bladwijzers worden lokaal in de browser bewaard.
